# Ghana Quiz Game

Interactive multiple-choice quiz in Python that tests general knowledge about Ghana and keeps score.

## Features
- Multiple-choice questions on Ghana's history, culture and geography
- Questions shown with lettered options (A–D)
- Five random questions per round, scored out of 5
- Leaderboard of player scores

## Requirements
Python 3 (standard library only).

## Usage
```bash
python quiz_game.py
```
